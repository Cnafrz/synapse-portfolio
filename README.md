# SynapsePortfolio

یک پورتفولیوی شخصی با تم تاریک و سینماتیک که ترکیبی از توسعه نرم‌افزار، تولید موسیقی و هنرهای تجسمی را به نمایش می‌گذارد.

## تکنولوژی‌های استفاده‌شده
- **هسته:** React 19, Vite, TypeScript
- **استایل‌دهی:** Tailwind CSS v4, Radix UI
- **انیمیشن و ۳ بعدی:** Framer Motion, GSAP, Three.js, Lenis
- **صدا:** Howler.js
- **بک‌اند:** Express

## ویژگی‌ها
- **Hero Section:** افکت‌های Generative WebGL، پس‌زمینه پارتیکل (Particle) و نشانگر ماوس اختصاصی.
- **درباره من:** طراحی Split-screen با ویژوالایزر فرکانس صدا و آمار شخصی.
- **گالری پروژه‌ها:** قابل فیلتر شدن بر اساس حوزه‌های توسعه وب، موسیقی و هنرهای تجسمی.
- **موسیقی:** موزیک پلیر اختصاصی با انیمیشن وینیل و Waveform.
- **گالری هنر:** نمایش تصاویر با قابلیت Lightbox و اسلایدر مقایسه قبل/بعد.
- **Command Palette:** پشتیبانی از شرت‌کات‌های کیبورد (مثل Ctrl+K).

## نحوه اجرا
برای راه‌اندازی پروژه روی سیستم محلی خود، مراحل زیر را دنبال کنید:

1. نصب وابستگی‌ها:
   ```bash
   pnpm install
   ```
2. اجرای سرور توسعه (Development):
   ```bash
   pnpm run dev
   ```
3. بیلد پروژه برای پروداکشن:
   ```bash
   pnpm run build
   pnpm run start
   ```
